1 Carga de Datos

📂

El objetivo inicial es crear la base de datos miscelanea e importar los archivos JSON. Esto se realiza desde la terminal del sistema operativo.

▶ Importar la colección 'books' 

mongoimport --verbose --db miscelanea --collection books --file "C:\ruta\act-2-books.json"

▶ Importar la colección 'companies' 

mongoimport --verbose --db miscelanea --collection companies --file "C:\ruta\act-2-companies.json"

2 Exploración de Colecciones

🔍

▸ Extraer un documento de forma «bonita»

Se utiliza findOne() para traer el primer registro formateado.

db.books.findOne()

▸ Distintas categorías (books)

db.books.distinct("categories")

▸ Distintos estados (books)

db.books.distinct("status")

▸ Consulta y Proyección ($gte, $lt)

db.books.find({longDescription: {$gte: "A", $lt: "B"}}, {title: 1, longDescription: 1})

¿Qué hace?: Busca libros cuya descripción larga (longDescription) empiece con la letra "A". Además, incluye una proyección {title: 1, longDescription: 1} para que el resultado en pantalla solo muestre esos campos específicos.

▸ Filtrar tamaño de arreglo ($size)

db.books.find(
    { longDescription: {$gte: "A", $lt: "B"}, authors: {$size: 2}, status: "PUBLISH" }, 
    { title: 1, longDescription: 1, status: 1, authors: 1, _id: 0 }
)

⚙ Modificadores de Salida (.toArray y .forEach)

.toArray() convierte el cursor en un arreglo JavaScript en memoria. .forEach(...) recorre ese arreglo y permite formatear la salida en la consola.

db.books.find({ longDescription: {$gte: "A", $lt: "B"}, authors: {$size: 2}, status: "PUBLISH" }, { title: 1, longDescription: 1, status: 1, authors: 1, _id: 0 }).toArray().forEach(function(valor, indice, array){print("Titulo: " + valor.title + " Autho 1: " + valor.authors[0] + " Author 2: " + valor.authors[1] + " Registro No. " + indice);})

3 Consulta la colección 1 (Books)

📚

▸ Tamaño de la colección (en bytes)

db.books.dataSize()

▸ ¿Cuántos libros tiene la colección?

db.books.countDocuments()

▸ 200 o más páginas

db.books.countDocuments({ pageCount: { $gte: 200 } })

▸ Entre 300 y 600 páginas

db.books.countDocuments({ pageCount: { $gte: 300, $lte: 600 } })

▸ 0 páginas

db.books.countDocuments({ pageCount: 0 })

▸ Distinto de 0 páginas ($ne)

db.books.countDocuments({ pageCount: { $ne: 0 } })

▸ Libros publicados

db.books.countDocuments({ status: "PUBLISH" })

▸ Libros NO publicados

db.books.countDocuments({ status: { $ne: "PUBLISH" } })

4 Consulta la colección 2 (Companies)

🏬

▸ Tamaño y Cantidad total

db.companies.dataSize()
db.companies.countDocuments()

▸ >= 600 empleados

db.companies.countDocuments({ number_of_employees: { $gte: 600 } })

▸ Fundadas en 1996, 1997, 2001 y 2005

Uso del framework de agregación para obtener totales agrupados en una sola petición.

db.companies.aggregate([
  { $match: { founded_year: { $in: [1996, 1997, 2001, 2005] } } },
  { $group: { _id: "$founded_year", total: { $sum: 1 } } }
])

▸ Dedicadas a «web» o «mobile» (Operador $in y proyección)

db.companies.find(
    { category_code: { $in: ["web", "mobile"] } },
    { name: 1, description: 1, number_of_employees: 1, email_address: 1, founded_year: 1, founded_month: 1, founded_day: 1, _id: 0 }
)

▸ Videojuegos en orden descendente

Uso de .sort({campo: -1})

db.companies.find(
    { category_code: "games_video" }
).sort({ founded_year: -1 })

▸ Única y exclusivamente 2 oficinas en SF

db.companies.find({
    offices: { $size: 2 },
    "offices.city": "San Francisco"
})

💡 Análisis Complejo

▸ 2001-2005, >=500 emp., videojuegos O música

db.companies.find(
    { founded_year: { $gte: 2001, $lte: 2005 }, number_of_employees: { $gte: 500 }, category_code: { $in: ["games_video", "music"] } },
    { name: 1, homepage_url: 1, twitter_username: 1, number_of_employees: 1, _id: 0 }
)
¿Alguna empresa se dedica a videojuegos y música a la vez?
No. En este esquema, el campo category_code guarda un valor de tipo String (cadena única), no un Array. Por ende, un documento solo puede tener asignada una categoría a la vez.

▸ Adquisiciones en 2007 (>= 10M USD), videojuegos, sede Culver City

Se utiliza la notación de punto entre comillas para sub-documentos.

db.companies.find(
    { category_code: "games_video", "acquisition.acquired_year": 2007, "acquisition.price_amount": { $gte: 10000000 }, "offices.city": "Culver City" },
    { name: 1, "acquisition.acquired_month": 1, "acquisition.acquired_day": 1, _id: 0 }
)
